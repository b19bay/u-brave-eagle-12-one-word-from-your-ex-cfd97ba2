One word from your ex: `practice` — the word an ex would use to describe you, because the whole relationship was rehearsal for the real thing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node --experimental-strip-types main.ts
```

The program writes exactly one word, `practice` (8 characters, 8 bytes, no trailing newline), to `/output/entry.txt`, with a runtime gate asserting it is exactly one word of 1–24 characters.
